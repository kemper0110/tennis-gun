# Требования

- старт/стоп
- регулировка скорости двигателя корзины
- регулировка скорости двигателя шутера
- отслеживание выставленных параметров

# UI

Кнопка старт/стоп большая и по центру.
Ниже 2 ползунка.
Ползунок скорости двигателя корзины слева.
Ползунок скорости двигателя шутера справа.

Кнопка отображает состояние старт/стоп.
На ползунках процент скорости.

# BLE API

[ble-api.md](ble-api.md)

Панель управления подключается к плате через Web Bluetooth. При потере соединения плата останавливает моторы и сохраняет выставленные скорости.
